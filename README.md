# editor-sandbox

Test repository for the n7.world content editor (OmniBrew/omnibrew, plan/33). The editor's
sandbox backend and its automated test open, update and close pull requests here, never on
OmniBrew/masseffect-5e-data. The files are a few copies from that repo, in the same layout.

Nothing here is published. Test pull requests are closed and their branches deleted after each run.
